- Medigo’s original checkout had uninitialized submodules. A separate isolated clone at `medigo-analysis/` successfully fetched all three pinned submodules; the original `reference-repos/Medigo` checkout was not modified.
- OpenEMR’s working-tree filesystem is sparse/empty, but its `HEAD` git object contains the full source tree; it was inspected with `git show`/`git ls-tree` without mutating the checkout.
- No dependency-license audit was run against lockfiles; the license matrix flags this as required before commercial distribution.
