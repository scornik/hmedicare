## Findings
HCW@Home has the strongest directly evidenced live-consultation design: consultation states, participant admission, invitation tokens, message/read receipts, explicit mediasoup topology, media permissions/events, and reminder/feedback/payment relationships are in the Prisma schema and package metadata (`backend/prisma/schema.prisma`, `backend/package.json`). This is a strong architectural reference, but it does not prove production-grade ICE/TURN, recording, reconnect, consent, or delivery guarantees.

TPT Doctor has a more complete EHR boundary and a `TelemedicineSession` model, but the checked-out evidence is less specific about the media plane. `apps/api/package.json`, the telemedicine modules, and deployment configuration should be inspected and tested before treating it as a reusable call implementation.

No checked-out source substantiates Jitsi, Agora, WhatsApp message sending, SMS fallback behavior, low-bandwidth adaptation, or a chamber serial queue in any repository. HCW’s `WHATSAPP` enum/template and Twilio declaration are integration hooks, not proof of a finished Bangladesh delivery workflow.

OpenEMR is a meaningful telemedicine reference through the ComLink custom module: `interface/modules/custom_modules/oe-module-comlink-telehealth/` contains teleconference-room, video-registration, patient-portal, calendar, session-repository, invitation-mailer, notification, and telehealth-auth components plus `sql/table.sql`. The provider/media runtime still requires execution review; do not infer a specific WebRTC/Jitsi/Agora implementation from the module name alone.
